# Verification — Shell Method (pilot)

> 本文件是"两方独立算出、结果一致"的存档。任何与此表冲突的代码都是代码错了。

## 例子

区域：`f(x) = 4 − x²`，`x ∈ [0, 2]`，与 x 轴、y 轴围成。绕 **y 轴** 旋转。

## 1. 解析解

```
V = 2π ∫₀² x·f(x) dx
  = 2π ∫₀² (4x − x³) dx
  = 2π [2x² − x⁴/4]₀²
  = 2π (8 − 4)
  = 8π = 25.132741228718345
```

## 2. 交叉验证 ① — 换一种方法（Disk 法，对 y 积分）

`x² = 4 − y` ⇒ 半径² = 4 − y，y 从 0 到 4

```
V = π ∫₀⁴ (4 − y) dy = π [4y − y²/2]₀⁴ = π(16 − 8) = 8π   ✅ 与 Shell 法一致
```

## 3. 交叉验证 ② — 换一条计算路径（自适应 Simpson 数值积分）

`shellVolumeNumeric()` 不使用闭式原函数，误差 < 1e-10。
与 `shellVolumeExact()` 比对通过 —— 这一条专门用来抓 `curve.xF` 写错这类肉眼看不出的错误。

## 5. ⭐ 关键教学点：`2πrhΔx` 不是近似

取**中点**半径 r 时：

```
π(R² − r_in²)h  where R = r + Δx/2,  r_in = r − Δx/2
= π[(r + Δx/2)² − (r − Δx/2)²] h
= π(2rΔx) h
= 2πr · h · Δx                      ← 恒等式,不是近似
```

数值验证（x = 1.2, Δx = 0.3, h = f(1.2) = 2.56）：

| | 值 |
|---|---|
| `2πrhΔx` | 5.790583579 |
| `π(R²−r²)h` | 5.790583579 |
| 差 | 8.88e-16（浮点噪声） |

**结论**：Shell Method 里唯一的近似来自"壳的高度在 Δx 内当作常数"，
和"把壳展开成长方体"没有关系。教科书基本不讲这一点，本项目把它做成 Stage 5b。

⚠️ 用左/右端点半径会破坏这个恒等式。所以本项目的黎曼和**一律用中点**。
