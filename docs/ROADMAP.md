### W6 — 新链:为什么 ∫dx/x 偏偏是 ln

**这是本次最重要的一条。** 学生真正的困惑不是"记不住",而是:
> 「所有幂都给 x^(n+1)/(n+1),凭什么 n = −1 给一个完全不同种类的函数?」

诊断:幂法则在 n = −1 处**不是给出另一个答案,而是分母为 0、公式坏掉了**。
教科书直接换一个公式,学生只能当特例背下来。

- **路由 id**:`log-integral`
- **依赖**:`riemann-sum`(面积)、`limits`(0/0 与可去间断)
- **新增数学**:`src/math/logIntegral.ts`
  - `powerAntiderivativeAt(n, b)` = `(b^(n+1) − 1)/(n+1)`,**n = −1 必须返回 `null`**(不是 NaN)
  - `areaUnderReciprocal(t)` = `∫₁ᵗ dx/x`,用 `adaptiveSimpson` 算,**不许直接调 `Math.log`**
    —— 那等于把要证的结论当前提。`Math.log` 只能出现在**测试**里作为第二条独立验证路径。
- **⚠️ 定义域**:`1/x` 在 0 处有极点,整条链只在 `x > 0` 上工作。采样沿用 `limits.ts` 的
  `PartialFunction` 约定(无定义返回 `null`)。

#### 分镜(8 步,数字已双路径验证)

| # | 标题 | 屏幕上发生什么 | 可拖 | 公式 |
|---|---|---|---|---|
| 1 | The power rule has a hole in it | 并排列出 n = 2, 1, 0, −2 的原函数,都好用;轮到 n = −1 时公式里的 `n+1` 高亮成红色 | — | `∫xⁿdx = x^(n+1)/(n+1)`,`n=−1` 处分母为 0 |
| 2 | Watch the formula break | 画 `∫₁²xⁿdx = (2^(n+1)−1)/(n+1)`,拖 n 向 −1 逼近 | `n` | 见下表 |
| 3 | It is 0/0, not nonsense | 点明这是**可去间断**,和 limits 链第 1 步是同一个故事 | — | `n=−1` → `0/0`,极限 = **0.693147** |
| 4 | So what is that number? | 切到 `y = 1/x`,阴影出 `[1,2]` 下的面积,数值 = 0.693147 —— **同一个数** | — | `A(2) = 0.693147` |
| 5 | ⭐ Stretch and squash | 把 `[1,2]` 的区域横向拉 2 倍、纵向压 1/2 倍,它**正好盖住 `[2,4]` 的区域**。面积不变 | `b` | `[1,2]` 与 `[2,4]` 面积都是 **0.693147** |
| 6 | Area turns × into + | 由第 5 步推出 `A(bc) = A(b) + A(c)` | `b`, `c` | `A(2)+A(4)=2.079442=A(8)` |
| 7 | Only logs do that | 把乘法变加法的函数只能是对数。底数由 `A = 1` 定出 | `t` | `A(e)=1`,`e = 2.718282` |
| 8 | That is why it is ln | 回到第 1 步那张表,把 n = −1 那一格填上 `ln\|x\|` | — | `∫x⁻¹dx = ln\|x\| + C` |

**第 2 步钉死的数值**(独立脚本已验):

| n | ∫₁²xⁿdx |
|---|---|
| −0.5 | 0.828427 |
| −0.9 | 0.717735 |
| −0.99 | 0.695555 |
| −0.999 | 0.693387 |
| −0.9999 | 0.693171 |
| −1 | **无定义(0/0)** |
| 极限 | **0.693147** = ln 2 |

**面积表**:`A(2)=0.693147` · `A(4)=1.386294` · `A(8)=2.079442` · `A(16)=2.772589`
(逐项都是 A(2) 的整数倍 —— 第 6 步的证据)

**第 5 步是整条链的支点**,务必做对:`[2,4]` 那块**更宽更矮**,面积却和 `[1,2]` 一模一样。
代换证明写进 narration:`x = bu` ⇒ `∫_b^{bc} dx/x = ∫₁^c b·du/(bu) = ∫₁^c du/u`。
`1/x` 是唯一在"横拉 b、纵压 1/b"下**回到自己**的幂函数 —— 这才是 ln 出现的真正原因。

### W7 — 新链:∫tan x dx 那个又长又怪的答案

> 「`−ln|cos x|`?我怎么可能猜到这个。」

诊断:学生以为要靠灵感。真相是**根本不用猜** —— 分子恰好是分母的导数(差个负号)。

- **路由 id**:`tan-integral`
- **依赖**:**必须在 W6 之后**(`∫u′/u = ln|u|` 是 W6 的结论 + 链式法则)
- **新增数学**:`src/math/tanIntegral.ts`,同样**不许直接调 `Math.log`** 算主路径
- **⚠️ 极点**:`tan` 在 `π/2` 发散,整条链限制在 `[0, π/3]`,采样沿用 `PartialFunction` 约定

#### 分镜(7 步)

| # | 标题 | 内容 | 公式 |
|---|---|---|---|
| 1 | An answer you would never guess | 直接把 `−ln\|cos x\|` 摆出来,承认它看着莫名其妙 | — |
| 2 | Split it into what it really is | `tan x = sin x / cos x`,上下分别画出来 | `tan = sin/cos` |
| 3 | ⭐ Look at the derivative of the bottom | `(cos x)′ = −sin x` —— 分子就是分母的导数,只差一个负号。这一步是全链的支点 | `(cos)′ = −sin` |
| 4 | You have seen this shape before | 抽象成 `∫u′/u`。回指 W6:`1/x` 的积分是 `ln` | `∫u′/u\,dx = ln\|u\|` |
| 5 | Put it together | `∫tan = −∫(cos)′/cos = −ln\|cos x\|` | 完整推导三行 |
| 6 | Check it numerically | 阴影 `[0, π/3]` 下 tan 的面积,与 `−ln(cos π/3)` 对照 | 两者都是 **0.693147** |
| 7 | ⭐ The same number as before | 点明 `∫₀^{π/3} tan = ln 2 = A(2)` —— 和 W6 第 4 步**完全同一个数**,给出跳转链接 | `= ln 2 = 0.693147` |

**钉死的数值**(解析与数值积分双路径,差 < 4e-12):
`∫₀^{π/4} tan = 0.346574` · `∫₀^{π/3} tan = 0.693147`

第 7 步那个呼应是白送的礼物,一定要用上:两条完全不同的链落在同一个数上,
学生会真切感到这些东西是**一个整体**而不是一堆孤立公式。

### W8 — 新链:ε–δ,极限定义到底在说什么

> 「那一堆符号看着像天书。」

诊断:ε–δ 被当成"严谨版的极限"来教,于是显得多余。它其实是一场**挑战—应答游戏**,
而且它是唯一能说清"极限不存在"到底什么意思的东西。

- **路由 id**:`epsilon-delta`
- **依赖**:`limits`(它把数值逼近讲完了,ε–δ 是它的严格化)
- **新增数学**:`src/math/epsilonDelta.ts`
  - `deltaForLinear(m, eps)` = `eps/|m|`
  - `bandCheck(fn, a, L, eps, delta)` → `{ ok, worstX, worstY }`,**真的采样检验**,
    不是套公式判定。失败时必须给出**具体的反例点**(第 6 步要用)
- **⚠️ 无引擎改动**:两个联动滑块 + 通过/失败状态,现有 `Stage.controls` 与 `formula` 足够表达

#### 分镜(8 步)

| # | 标题 | 内容 | 可拖 |
|---|---|---|---|
| 1 | A game, not a definition | 介绍规则:对手先画一条**水平带**(半高 ε),你要回一条**竖直带**(半宽 δ) | — |
| 2 | The challenge | `f(x)=2x+1`, `a=1`, `L=3`。对手给 ε = 0.5,水平带 `(2.5, 3.5)` 亮起 | `ε` |
| 3 | Your response | 拖 δ。当竖直带内的曲线**整段落在水平带里**,边框变绿 | `δ` |
| 4 | ⭐ Why δ = ε/2 | 代数推出来:`\|2x+1−3\|<ε ⟺ 2\|x−1\|<ε ⟺ \|x−1\|<ε/2` | `ε` |
| 5 | The opponent gets greedier | ε 逐级缩小 `0.5 → 0.2 → 0.1 → 0.01`,δ 自动跟着 `ε/2` | 自动 |
| 6 | ⭐ When you cannot answer | 换成 limits 链那个跳跃函数 J,试证 `L = 2`,取 `ε = 0.5`。**任何 δ 都失败**,并把反例点标出来 | `δ` |
| 7 | Steeper means smaller δ | 一般线性 `f = mx + c` 给出 `δ = ε/\|m\|`。斜率越陡,同样的 ε 要求越小的 δ | `m`, `ε` |
| 8 | Prove a limit law with it | 用 ε–δ 证**常数倍法则**:给定 ε,对 f 用 `ε/\|c\|` 拿到 δ | `c`, `ε` |

**第 2–5 步钉死的数值**:

| ε | δ = ε/2 | x ∈ (1±δ) 时 f 的范围 | ⊂ (3±ε)? |
|---|---|---|---|
| 0.5 | 0.25 | (2.5000, 3.5000) | ✓ |
| 0.2 | 0.1 | (2.8000, 3.2000) | ✓ |
| 0.1 | 0.05 | (2.9000, 3.1000) | ✓ |
| 0.01 | 0.005 | (2.9900, 3.0100) | ✓ |

**第 6 步的反例**(J(x) = x+1 (x<1), x+2.5 (x>1),L=2,ε=0.5,要求 J ∈ (1.5, 2.5)):

| δ | x = 1+δ 处 J | 在带内? |
|---|---|---|
| 0.5 | 4.0000 | ✗ |
| 0.1 | 3.6000 | ✗ |
| 0.01 | 3.5100 | ✗ |
| 0.001 | 3.5010 | ✗ |

narration 要说清:**不是"δ 还不够小"**,是右侧的值卡在 3.5 附近**根本不动**。
任何 δ > 0 都失败 ⇒ 极限不是 2。这就是"极限不存在"的严格含义。

**第 8 步的证明**(常数倍法则):
给定 ε,对 f 取容差 `ε/|c|` 得到 δ;则 `|x−a|<δ ⇒ |f−L|<ε/|c| ⇒ |c·f−c·L| = |c||f−L| < ε` ∎
数值示例:`c = 3, ε = 0.6` → f 的容差 `0.200000`;`ε = 0.06` → `0.020000`。
narration 点明:**ε/|c| 不是凑出来的,是"预算分配"** —— 这正是学生看到 ε/2 时觉得随意的地方。

### W9 — 之后的链(按此顺序,一次一条)

审计建议的四条,顺序按依赖排:

1. **FTC**(微积分基本定理):累积函数 `A(x)=∫ₐˣf`,拖 x 看 `A` 的斜率就是 `f`。
   `RiemannBars` 已经就绪。**这条应该排在最前** —— 它是 Riemann 链的直接续集。
2. **链式法则**:两个齿轮/两段速度的复合,`dy/dx = dy/du · du/dx`。
3. **乘积法则**:矩形面积增量 `Δ(uv) = uΔv + vΔu + ΔuΔv`,最后一项是二阶小量。
   这条**几何上最漂亮**,一个矩形的两条边同时变长就讲完了。
4. **u-代换**:⚠️ 注意 W7 已经把 `∫u′/u` 这个最重要的特例讲透了,
   做这条时**从 W7 回指**,不要重讲一遍。
