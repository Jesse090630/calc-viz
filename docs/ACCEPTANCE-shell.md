## 人工验收

### 逐步

- [ ] **1 The region** — 抛物线顶点 y = 4 完整可见没被切;区域从 x=0 填到 x=2;刻度 1,2 和 1–4 都能看清
- [ ] **2 One thin strip** — 黄色矩形立在 x=1.2;拖 `position x` 时**矩形高度自动跟着曲线走**(这是本步唯一要传达的事);拖 `width Δx` 时矩形变胖变瘦;矩形表面干净,没有条纹/摩尔纹
- [ ] **3 Sweep** — 进入后**先转相机(约 1.1 秒),等相机停稳矩形才开始转**。绝不能同时动。转完是一个中空圆筒,黄色矩形停在接缝处
- [ ] **4 Dimensions** — 四个标注都在:radius(红线从轴指到壳)、height(蓝线)、thickness、**circumference 有一圈青色的环画在壳顶**。公式面板高亮的是 circumference 那一行
- [ ] **5 Unroll it** — 圆筒剪开摊平成一块板;摊平后 `length = 2πx = 7.54`;**没有 y 轴穿过这块板**(板已经不绕轴了,画轴是误导)
- [ ] **5b Not an approximation** — `slab` 和 `ring` 两个数字**逐位完全一样**(5.790583579)。这是本步的全部意义
- [ ] **6 Many shells** — 拖 n 从 1 到 40,壳越来越多越来越薄;公式里 sum 和 error 实时变;n=8 时 error ≈ 0.7812%
- [ ] **7 Let Δx → 0** — n **按 4 → 8 → 16 → 32 → 64 逐级跳**(不是连续爬)。每跳一级,error 大致缩到原来的 1/4:3.1250% → 0.7812% → 0.1953% → 0.0488% → 0.0122%
- [ ] **8 The formula** — 最后一行 `= 8π ≈ 25.1327`,与第 7 步收敛到的数字对得上
