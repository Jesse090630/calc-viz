## 问题清单(按优先级)

### P1 · 教学或可用性

1. **Unit Circle 移动端取景裁切。** 390×844 的第 5–7 幕里,单位圆左缘和
   `2π` 波形右端贴出画布;桌面端完整。核心同步线仍可见,但“完整一圈 → 完整一波”
   的说服力被削弱。不能加 CameraPreset;修复只能留在概念场景/现有 `wide` 方案内。
2. **39/47 幕 narration 超过一句。** AGENTS.md §3 明确要求每幕 ≤ 1 句;
   Riemann 8 幕符合,其余旧链共 32 幕不符合;未提交的 Unit Circle 7 幕已在 T1 内修正并加回归测试。
3. **首页依赖顺序有一处倒置。** Riemann → Shell → Disk 的前三张顺序正确且必须保留,
   但 Derivative 排在 Limits 前;最小修正是只交换这两张,Unit Circle 可继续独立放末尾。

### P2 · 移动端与无障碍

4. **移动端导航在五条链需要滚动面板才能看到。** Shell、Disk、Limits、Derivative、
   Unit Circle 的 aside 都会内部滚动;键盘导航正常,但触屏用户初见时看不到底部前进按钮。
   Riemann 最终幕刚好不需要滚动。
5. **返回链接覆盖绘图区。** 390px 下 `← all topics` 与多条链的 y 轴顶端/刻度处在同一角落,
   不阻断交互,但会遮挡数学标记。
6. **缺少明确的键盘焦点样式。** 首页卡片、返回链接和导航按钮主要依赖浏览器默认焦点环;
   hover 有设计,focus-visible 没有同等级反馈。
7. **动画没有 `prefers-reduced-motion` 路径。** 当前所有 autoplay 都会运行;
   对减少动态效果的系统偏好没有响应。
8. **Canvas 没有文本替代说明。** 公式与 narration 可读,但 WebGL 图形本身没有
   `aria-label` / 描述关联,屏幕阅读器无法知道当前几何发生了什么。

### P3 · 性能与一致性

9. **首屏一次加载六条链和全部 Three.js 场景。** `App.tsx` 静态 import 所有场景,
   首页也承担约 404 KB gzip 的 JS;可在不改 engine 的前提下做按路由动态加载,
   但这属于结构性优化,不应在收尾期顺手重构。
10. **语气有英美拼写混用。** 首页使用 `memorised`,若干 narration 使用美式表达;
    不影响理解,但最终文案统一时应选定一种。
11. **颜色语义总体通过。** 六条链的半径/横向量=红、高度/函数值=蓝、当前对象=黄、
    新量=青、结果=绿没有发现反转;场景中的浅色十六进制主要是对应语义的标签浅色,
    暂无必须修复的漂移。

## 建议实施边界

若进入实际打磨,建议只做 P1 三项与 P2 的 4–6;把 reduced motion、Canvas 辅助描述和
路由级代码分割拆成独立任务,避免收尾期大重构。
